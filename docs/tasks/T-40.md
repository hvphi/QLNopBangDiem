# T-40 · Dropdown Khoa và so khớp điểm PDF với file xuất daotao

## Mục tiêu
P.ĐT lọc Khoa bằng dropdown và đối chiếu điểm trong PDF đã ký với Excel/CSV xuất từ daotao qua nút So Khớp sau cột trạng thái.

## Ngữ cảnh cần biết
Người dùng chọn nguồn file Excel/CSV, chưa kết nối trực tiếp VKU. Kết quả chỉ đối chiếu với file cán bộ chọn; không công bố điểm đang sống trên hệ thống trường.

## Phạm vi
**Trong:** danh mục khoa theo scope courses, nút/cột training, đọc PDF bảng và file nguồn, ghép cột, kết quả theo MSSV/điểm/lệch/thiếu; API quyền/version/CSRF và tests.
**Ngoài:** kết nối/scrape daotao thật, sửa PDF/điểm, tự duyệt hoặc lưu nguồn điểm plaintext.

## Đầu vào đã có
PDF encrypted vault, pdfplumber/openpyxl bundled, courses/submissions API, comparison dialog UI dùng detail-dialog.

## Việc phải làm
Đọc bảng PDF có số thẻ và cột điểm; từ chối dữ liệu mơ hồ/trùng/không đọc được. Đọc XLSX/CSV, xác định cột mã SV, cho ghép từng cột điểm. Không kết luận khớp khi thiếu dữ liệu/cột. Đối chiếu đúng PDF version và quyền training, không ghi score vào audit.

## Quy ước bắt buộc
Giữ nguyên PDF. CSRF/RBAC/version máy chủ; dữ liệu tham chiếu chỉ xử lý tạm, không thay điểm/hồ sơ. File <=20MB, giới hạn trang/dòng.

## Test phải viết
- PDF thật component/final/guidance/multipage; header/số thẻ/cột điểm đúng, không nhầm chữ/ghi chú.
- CSV/XLSX đọc mã SV, duplicate/invalid/header lỗi bị từ chối.
- Decimal comma/zero/missing/extra/mismatch/partial/blank xử lý đúng.
- API training only, CSRF/version đúng, không sửa PDF/state.
- E2E dropdown, cột So Khớp, file/mapping/kết quả và lưu trữ cũ.

## Định nghĩa "xong"
Dropdown và So Khớp hoạt động với file nguồn, báo sai khác rõ ràng và không làm thay đổi bảng điểm.

## Cạm bẫy đã biết
Điểm chữ không phải điểm số; ô trống không phải 0. Chưa ghép đủ cột không được báo khớp toàn bộ. File tham chiếu cần đúng lớp/kỳ và cán bộ xác nhận.

## Đã làm gì
Dropdown Khoa theo courses; cột So Khớp training ngay sau trạng thái. Đọc nguyên bản PDF và nguồn XLSX/CSV, ghép cột theo MSSV, báo lệch/thiếu/thừa/chưa đầy đủ; không sửa điểm/PDF hay tự duyệt. Kiểm tra CSRF/quyền/version và audit chỉ tổng hợp. 10 parser/API tests, E2E, ảnh và typecheck PASS; cả 4 preview hồ sơ live HTTP 200 sau restart. Nguồn file theo lựa chọn người dùng, chưa kết nối VKU thật.

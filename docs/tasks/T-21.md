# T-21 · Chọn vai trò khi đăng nhập

## Mục tiêu
Người dùng chọn GV, TK, ĐT & BĐCL hoặc admin trên màn hình đăng nhập.

## Ngữ cảnh cần biết
Bốn vai trò hiện có tài khoản riêng. Chọn vai trò không cấp quyền mới; máy chủ đối chiếu quyền tài khoản.

## Phạm vi
**Trong:** dropdown vai trò, gửi lựa chọn đến API, chặn sai vai trò với thông báo rõ ràng.

**Ngoài:** thay tài khoản/email/mật khẩu, tự nâng quyền, thêm vai trò mới.

## Đầu vào đã có
Login API và form login, accounts teacher/head/training/admin.

## Việc phải làm
1. Thêm select bốn vai trò và hướng dẫn dùng tài khoản tương ứng.
2. API kiểm tra role sau kiểm tra mật khẩu, trước tạo session; request cũ không truyền role vẫn tương thích.
3. Kiểm thử API, E2E cả bốn lựa chọn và sai vai trò; restart.

## Quy ước bắt buộc
- Vai trò do admin cấp; không suy quyền từ lựa chọn UI/email.
- Không tạo session khi mật khẩu hoặc vai trò không đúng.
- Escape label và dữ liệu hiển thị.
